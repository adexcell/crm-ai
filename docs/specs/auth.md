# Инженерная спецификация модуля: Auth & Sessions (docs/specs/auth.md)

> **Статус**: В разработке (Sprint 1)
> **Стек реализации**: Go (backend-go), Python (backend-python), Vue 3 (frontend)
> **OpenAPI контракт**: `contracts/openapi.yaml`

---

## 1. Архитектурные инварианты (Definition of Done)
1. **Пароли**: Хэширование строго алгоритмом **Argon2id** (RFC 9106, параметры: $m=64\text{ МБ}, t=3, p=4$). Запрещено использовать быстрые хэши (SHA-256/MD5).
2. **База данных**: В таблице `refresh_tokens` хранятся **только SHA-256 отпечатки** (`token_hash`) токенов, никогда не сырые значения.
3. **Access Token (JWT)**:
   - Время жизни: **15 минут**.
   - Хранение на клиенте: **Строго в оперативной памяти (RAM)** JavaScript-рантайма (Pinia store). Запрещено сохранять в `localStorage` или `sessionStorage` (защита от XSS).
4. **Refresh Token**:
   - Передача клиенту: **Строго через куку `Set-Cookie`** с флагами `HttpOnly; Secure; SameSite=Lax`.
   - Время жизни: **30 дней**.
5. **Мультитенантность (Row-Level Security)**:
   - Токен пользователя привязан к текущей активной организации (`org_id`, `role`).
   - Если пользователь не состоит ни в одной организации: `org_id = uuid.Nil`, `role = ""`. Доступ разрешен только к `/api/v1/auth/me`, `/switch-org` и созданию новой компании. Доступ к бизнес-эндпоинтам (`/deals`, `/leads`) блокируется с `403 Forbidden`.

## 2. Матрица краевых кейсов (Edge Cases & Sad Paths)

| ID | Сценарий (Edge Case) | Ожидаемое поведение системы |
| :--- | :--- | :--- |
| **EC-01** | **Конкурентные F5 в 3+ вкладках** | **Grace Period (15 сек)**: Повторный запрос рефреша с только что отозванным токеном возвращает свежий Access-токен, не блокируя пользователя. |
| **EC-02** | **Replay Attack (Повтор токена)** | Запрос с отозванным токеном **спустя > 15 секунд**: сервер активирует Killswitch — отзывает ВСЕ сессии пользователя в БД и возвращает `401 Unauthorized` (`ERR_TOKEN_REPLAY_DETECTED`). |
| **EC-03** | **Timing Attack при входе** | Если пользователя с таким Email нет в БД, сервер всё равно выполняет `VerifyPassword` с фиктивным хэшем `dummyHash`, выравнивая время ответа (защита от сканирования базы пользователей). |
| **EC-04** | **Истечение срока по таймстемпу** | Если `ExpiresAt < time.Now()`, сервер просто возвращает `401 Unauthorized` и удаляет куку (`MaxAge: -1`). Killswitch ВСЕХ сессий НЕ активируется (это штатное истечение, а не взлом). |
| **EC-05** | **Атомарность регистрации** | Создание учетной записи `User`, организации `Organization` и членства `OrganizationMember` (`owner`) выполняется в **одной транзакции БД**. При ошибке любого шага — полный откат (Rollback). |
| **EC-06** | **Подделка tenant-контекста** | Попытка передать чужой `organization_id` пресекается на уровне проверки членства в БД (HTTP 403 Forbidden). |

## 3. Чек-лист приёмки Бэкенда (Go & Python)
- [ ] **Unit-тесты сервисного слоя**: Хэширование Argon2id, валидация DTO, проверка генерации слагов.
- [ ] **Конкурентный стресс-тест (`-race`)**: 10 одновременных запросов на `/api/v1/auth/refresh` от одного клиента завершаются успешно (проверка Grace Period).
- [ ] **Интеграционные тесты API**:
  - [ ] `POST /register`: успешная регистрация и создание `owner` в организации.
  - [ ] `POST /login`: валидация верных/неверных паролей, установка куки.
  - [ ] `POST /refresh`: корректная ротация токенов в БД.
  - [ ] `POST /logout`: отзыв токена и зачистка куки в браузере.
  - [ ] `POST /reset-password`: успешная смена пароля и принудительный отзыв всех старых сессий.

## 4. Чек-лист приёмки Фронтенда (Vue 3 + Pinia + Storybook)
- [ ] **Web Locks API (`navigator.locks`)**: Механизм кросс-вкладочной синхронизации запроса рефреша токена (только одна вкладка делает сетевой запрос).
- [ ] **Axios/Fetch Request Queue**: Очередь ожидания повторных запросов при получении 401 до момента завершения ротации.
- [ ] **Pinia Store**: Хранение токена строго в реактивном состоянии в памяти; очистка стейта при логауте.
- [ ] **Storybook**: Покрытие UI-компонентов авторизации (LoginForm, RegisterForm, OTPInput) всеми состояниями (Loading, Error, Disabled).
